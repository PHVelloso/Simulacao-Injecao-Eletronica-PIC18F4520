 Simulação de Injeção Eletrônica com PIC18F4520

Projeto desenvolvido em linguagem C utilizando o microcontrolador PIC18F4520 com simulação no Proteus.

 Descrição
Desenvolvimento de um simulador de injeção eletrônica capaz de realizar o cálculo do tempo de injeção a partir de parâmetros de temperatura e pulsos de rotação do motor.

 Objetivo
Simular a lógica básica de funcionamento de uma injeção eletrônica embarcada utilizando:
- Temperatura do motor
- Pulsos de rotação (RPM)

 Funcionalidades
- Leitura analógica via ADC
- Conversão de temperatura
- Cálculo de RPM por pulsos digitais
- Controle de LEDs simulando bicos injetores
- Exibição de RPM e temperatura em LCD 16x2

 Ferramentas utilizadas
- Linguagem C
- Microcontrolador PIC18F4520
- MPLAB X IDE
- XC8 Compiler
- Proteus 8.13

 Simulação
O projeto foi desenvolvido e testado utilizando o software Proteus, simulando:
- Sensor de temperatura via potenciômetro
- Sensor de rotação através de pulsos digitais (Dclock)
- Acionamento dos bicos injetores por LEDs
